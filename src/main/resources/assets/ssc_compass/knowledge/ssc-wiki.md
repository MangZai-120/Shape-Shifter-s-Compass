## 核心材料与功能物品

### 共鸣催化剂

它也许可以让你的变化更进一步..永久性的。你真的要这么做么？
用途
食用后恢复 2点（）饥饿值与 1点（）饱和度，并使处于第 3 阶段的玩家转变为永久阶段。

### 催化剂

当你接触它时，你体内的魔法似乎有所反应。

用途
食用后恢复 2点（）饥饿值与 1点（）饱和度，并大幅增加玩家的本能值。
如果此时玩家拥有咒文Buff，食用催化剂将直接进入对应的第 1 阶段。（睡一觉就能解决的问题真的需要催化剂么）

### 强效抑制剂

蕴含着更强力的黄金魔力。

用途
食用后恢复 2点（）饥饿值与 1点（）饱和度。
并将处于第 3 阶段的玩家转变为第 2 阶段，如果为 1 、2 阶段则转变为无阶段，对永久阶段（第 4 阶段）玩家无效。

### 未加工的月之尘

在诅咒之月升起时，一些生物掉落的奇怪物质。

用途
在工作台中合成幻形者之书、塑形核心以及月尘基质或在锻造台将钻石装备升级为塑形装备。
来源
在诅咒之月事件期间击杀生物掉落。

### 抑制剂

当你接触它时，你体内的魔法似乎平静了一些。

用途
食用后恢复 2点（）饥饿值与 1点（）饱和度。
并将处于 2 阶段的玩家转变为 1 阶段的玩家，也能使1阶段的玩家转变为无阶段，对第 3 阶段与永久阶段（第 4 阶段）的玩家无效。

### 月尘基质

悬浮在蜂蜜中的月尘。

用途
合成抑制剂，强效抑制剂，催化剂和共鸣催化剂
酿造月尘药水，喷溅型月尘药水和滞留型月尘药水。

### 极效抑制剂

(创造模式物品)由超越这个世界的力量制成，可以逆转永久形态。

用途
食用后恢复 2点（）饥饿值与 1点（）饱和度，并使处于任意阶段的玩家转变为无阶段。
来源
仅可以在创造模式下获得。

### 塑形核心

用途
可在锻造台上与钻石装备和未加工的月之尘相结合，将其升级为对应的塑形装备。
也可在锻造台上与下界之星为工具/装备塑形，使其不受形态/阶段限制。
来源
通过工作台合成获得。

### 月尘纯晶

精炼后的月尘结晶，可用于制作提升形态能力的饰品与工具。
用途
合成饰品。

### 灵质碎布

用于酿造胡狼咒文药水的材料，击杀咒文彷徨狼灵有概率掉落该物品。

### 蛛网胶滴

可用于制作结露蛛网，也可用于酿造蜘蛛咒文药水。
可通过击杀咒文蜘蛛获得。

### 液化茧体

注意：在1.9.2版本之前使用漏斗提取流食囊仅能提取出1个。
用于制作流食囊的方块，在背包中手持蜘蛛网右键点击堆肥桶得到，同时会消耗较多的蛛网值，每次获得一个。

与原版堆肥桶机制几乎相同，但是只能放入肉类包括腐肉，每次填充有概率增加1层，填充至3层后等待片刻，此时可以右键取出4-6个流食囊。
漏斗可以从堆肥桶顶部输入可堆肥的肉类；也可以从堆肥桶底部取出流食囊。
作者就是复制粘贴堆肥桶的代码

### 附魔金苹果

用途

### 结露蛛网

一张看起来非常漂亮的蛛网，该物品可加快处于蜘蛛第1、2阶段的玩家向下一阶段的转变速度，其它机制与原版相同。
可由1个未加工的月之尘，1个蜘蛛网和1个蛛网胶滴合成。

### 流食囊

流体营养液的储囊，食用后果自负
玩家处于蜘蛛形态时适宜食用其实是喝的的食物，食用后回复6点（）饥饿值和9点（）饱和度。
获取方式：手持肉类包括腐肉对液化茧体右键使用获得，每次获得4-6个，或者拥有"can_loot_spider_fluid_cocoon"能力的玩家（蜘蛛3/4阶段）击杀拥有裹茧buff的非黑名单生物傀儡和骷髅肯定吃不了吧有概率掉落（40%掉落1~(血上限/4)个，除法向上取整）。
食用此物品会施加给玩家7.5秒的中毒1效果。不过真的有人看了道具描述还去使用吗 豹猫3/4阶段其实也能吃 和蜘蛛一样都有毒免

### 幻形者之书

'这本书的奥秘只会向幻形者展示'
注意：在 1.0.7 版本开启模组功能时死亡将间接导致玩家无法跳跃（状态效果残留），退出重进即可恢复（已在 1.0.71 及后续版本修复）。
用途
可用于开启模组功能，开启后可用于查看玩家的状态、外观描述、能力、劣势与本能。
启用前第 1 页（启用后）第 2 页（启用后）进行或完成本能中的行为时，本能值就会上升。当玩家状态更新时，幻形者之书中的内容也会随着改变。
来源
第一次进入世界时即可获得一本，也可通过工作台合成。
注意事项
如未打开本书将不会发生本模组的大部分功能，如幻形生物不会攻击玩家并给予状态效果，诅咒之月除外（测试一晚上发现没翻书发现白测导致红温了）。

### 瓶装暴雪

在玩家处于雪狐形态时使用的工具。以一些饥饿值为代价，右键凝结并发射出雪球，击中目标后造成2点（）伤害。
每发射一个雪球会消耗四分之一的饥饿值。

用途

## 刷怪蛋

### 咒文蝙蝠刷怪蛋

此段资料引用于“刷怪蛋 (Spawn Egg)”并与其保持同步更新。  编辑概述
刷怪蛋只能在创造模式下获得，右击方块立即生成一个生物，也可使用发射器。
但在和平模式下，由刷怪蛋生成的敌对生物会立即消失。
有幼年形态的生物的刷怪蛋对着对应的生物使用时，会生成幼年形态的生物。
创造模式下对着生物按下中键，就可以获得这个生物的刷怪蛋。

刷怪蛋可以用铁砧重命名，用它生成的生物会带上名字，也能触发命名牌彩蛋。
对准刷怪笼使用时，会改变其生成的生物。
历史
刷怪蛋在 Java 版 1.1 快照 11w49a 和 携带版 Alpha 0.7.0 中加入。
在 Java 版 1.13 以前，对应生物的刷怪蛋被称为 生成 <生物>（Spawn <mob>）；
在 Java 版 1.13 快照 18w20a 中被重命名为 <生物>刷怪蛋（<mob> Spawn Egg）；
但在基岩版直至预览版 1.20.70.21 中才被重命名。
在 Java 版 1.21.5 快照 25w08a 和 基岩版 预览版 1.21.70.24 中，所有刷怪蛋的纹理被大幅修改，以更好地表示具体的生物。

在维持奔跑时，通过掌握时机，你可以触发每次高度递增的三连跳。
你的跳跃暴击伤害会随着下落距离而增加，最高可以到达2倍。
由于你的体型，远程攻击难以命中你。
你的奔跑速度变得更快，你也可以在甜浆果丛中自如穿梭。
甜浆果可以给你带来更多的饥饿值。
狐狸信任你。它们不会主动跑开。
你现在可以在细雪上行走。

劣势：
寒冷的魔力组成了你的身体。它带来了一些副作用：
火焰与高温是你最大的敌人。你会受到额外的燃烧伤害，并且你身上的火焰不会自然扑灭，除非进入水中或者使用水瓶灭火。
当白天在炎热的沙漠群系，或者炽热的下界中时，你的最大生命值会大幅度减少。除此之外，温暖的平原群系对现在的你而言也热的难以忍受，位于其中时，你的最大生命值也会减少。
当你非常靠近岩浆或燃烧的火焰，或者在岩浆中时，你会逐渐受到伤害，即使有火焰免疫效果也一样。
腿甲与鞋不再适合你四足的身体结构。
由于不再有能够自如使用工具的双手，你挖掘方块的速度变得更慢。
你蓬松的毛皮进一步拖慢了你在水中的移动速度。
